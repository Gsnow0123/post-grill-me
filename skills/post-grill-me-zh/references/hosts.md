# 宿主能力

核心流程只有指令，不需要网络服务、API 密钥、MCP 服务、子代理或配套 skill。以下增强能力取决于当前宿主实际提供的工具和授权。

| 能力 | 可用时 | 不可用时 |
| --- | --- | --- |
| 关联对话 | 用只读列表与读取工具补充相关聊天，必要时查归档。 | 使用已提供材料，说明覆盖缺口。 |
| 代码背景 | 定向读文件或 diff，区分实现参照。 | 实现行为保持未验证。 |
| 持久记录 | 在当前模式与权限允许时写入约定目录。 | 聊天中保留短暂定摘要，并说明未保存。 |
| 右侧文件面板 | 在当前聊天面板打开已保存记录。 | 给文件链接；轻量校准仍可继续。 |

Codex 桌面**实际暴露这些工具时**，对话工具可能包括 `list_threads`、`read_thread`、`list_archived_threads`；文件面板工具可能是 `mcp__codex_app__open_in_codex`，参数为 `placement: "right"` 和 `target: { type: "file", path: 绝对路径 }`，省略 `threadId` 指向当前聊天。以当前工具模式为准，准确说明排队或失败状态。

不能假定 Codex CLI、IDE 扩展或其他 Agent Skills 客户端也有这些桌面工具。不为获得同样的视觉效果而新建/分叉聊天或伪造工具。读取关联聊天不等于获准向它们发消息或扫描无关账户历史。
