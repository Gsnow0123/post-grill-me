# Changelog / 更新记录

## 0.1.0 — 2026-10-27

- First public release with two standalone instruction languages: English and Simplified Chinese.
- Small-round assumption calibration and a separate memory-refresh entry point.
- Scoped multi-conversation context with provisional-version handling.
- Configurable feature-recap storage and optional desktop-panel presentation.
- Fictional examples, package validation, and manual regression cases.

首个公开版本：独立完整的中英双语 skill、短轮次理解校准、复习入口、多对话与版本范围识别、可配置记录位置、可选桌面展示、虚构示例与包检查。行为案例供手动测试，不代表模型通过率。
